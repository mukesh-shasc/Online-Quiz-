# 📝 Online Quiz App

A lightweight, responsive web-based quiz application built using pure **HTML, CSS, and Vanilla JavaScript**. Users can answer multiple-choice questions within a fixed time limit, view instant score evaluations, and restart the quiz.

---

## ✨ Features

* **Interactive Quiz Interface:** Dynamic question loading without page reloads.
* **Timer Countdown:** Fixed time per question/quiz with automatic submission when time expires.
* **Instant Score Calculation:** Direct evaluation showing total marks and percentage upon completion.
* **Responsive Design:** Styled cleanly using CSS Flexbox/Grid for mobile and desktop screens.
* **Progress Tracking:** Shows current question number out of the total set.

---

## 🛠️ Tech Stack

* **HTML5:** Page layout and structural content.
* **CSS3:** Custom styling, smooth button hover effects, and responsive layout.
* **JavaScript (ES6):** DOM manipulation, timer handling, and score evaluation logic.
